# Jane Music 更新说明

---

## 4.0.1（当前）

- **修复**：界面上右键不再弹出浏览器的「刷新 / 检查」菜单（WebView2 网页内核漏底）；
  输入框里的复制粘贴右键保留

  发现新版本时标题栏「Jane Music」旁边亮一颗 **NEW**，点它直达下载页；
  设置里也可以手动「检查更新」

## 4.0

一句话：界面整个用 Vue 重写，新变大窗模式（左封面右歌词），加了收藏和播放列表，三种窗口形态随便切；
之后又整体打磨了一轮手感与文案。

---

## 本轮打磨（界面与手感）

**大窗**
- 加宽到 860×600（原来是 760，偏方；加宽后长歌词少折行）
- 封面换成黑胶碟：盘体受光渐变 + 细密沟槽 + 两道斜向反光，封面当唱片标压在中间；播放时 26 秒转一圈
- 黑胶只在窗口被选中时转：切到别的窗口/最小化就停在原角度（这台机器软件合成下转盘约吃 0.7 个核，后台不白烧）
- 歌名歌手移到下方控制条左侧，右上是收藏 / 历史 / 榜单全曲 / 音量，两侧配平

**歌词**
- 当前唱的那句停在「中间偏上一行」，下方多露一句后续
- 上下各 40px 渐隐：滚动容器高度不是行高的整数倍，首尾半截行改成淡出，不再像被切断
- 字号可在设置里调（12~24，大窗比设定值再大 2px）
- 高亮只做颜色过渡（字号即时切换），避免长句折行跳动带动滚动漂移
- 悬停气泡柔化，只有一句歌词（纯音乐）时整句居中
- 去掉了滚动条与「点任意一句跳转」的提示语

**榜单**
- 切换入口统一收到标题栏右上角：大窗是带榜单名的胶囊，小窗是圆钮；设置里那套重复入口删掉
- 切换中 / 成功 / 已是当前榜 / 失败都有底部提示，不再无声无息

**其他**
- 底部补上收藏入口（心形，在左侧），小窗不显示；四个图标的视觉尺寸重新对齐
- 顶部提示条（toast）重做成玻璃小卡 + 状态点，不再是彩色文字条
- 全套提示文案重写，说人话（「歌词正在飞奔来的路上~」「《歌名》收进小抽屉了」等）
- 托盘菜单文案同步

## 新增

**大窗模式（默认）**
860×600：左边黑胶封面 + 歌名歌手，右边歌词整列常驻滚动（当前句红色放大），点任意一句歌词直接跳到那句；进度条通栏，底部控制一行排开。

**收藏**
底部左侧的心形图标，点一下收藏当前歌、再点取消；底部「我的收藏」弹层可回看，点歌名直接播放，也可一键清空。

**播放列表**
底部列表图标弹层列出当前榜单的全部歌，点歌名直接切过去，不用再随机碰。

**三种窗口形态**
- 大窗 860×600（默认）：黑胶封面 + 整列歌词
- 小窗 380×600：竖版布局，点封面看完整歌词
- 胶囊 340×84：从托盘图标右键 → 胶囊模式进入，能拖到屏幕任意位置
标题栏第一个圆图标在大窗/小窗间切换，下次打开回到上次所在的形态。

## 改进

- 前端整体用 Vue 3 重写（组件化，逻辑与界面分离），功能与 3.0 一一对应
- 模式切换按钮改为图标，胶囊入口从标题栏移进托盘菜单
- 三种模式均为固定尺寸、不可拖边缩放；窗口摘掉系统隐形边框，四角不露白边、不闪

---

*3.0 的全部功能保留：随机抽歌、五个榜单、歌词点句跳转、封面滚轮切歌、音量滚轮调节、音量淡入淡出、深浅色主题、窗口置顶、托盘常驻、播放历史、状态持久化、封面/音频缓存。*

## 更新方式

覆盖旧的 exe 就行，收藏、历史、榜单、音量、主题都保留在 `%APPDATA%\JaneMusic\state.json`，不用重新配。
`WebView2Loader.dll` 必须和 exe 放在同一个文件夹里。
